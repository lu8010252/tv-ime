# tv-ime 电视输入法

给安卓电视/投影用的轻量输入法，APK 很小，不带词库。

- **遥控器打字**：屏幕键盘有英文字母（大小写）、数字、常用符号；方向键移动，确定键输入，长按确定连删；BACK 收起键盘。
- **手机跨屏输入（含中文）**：电视输入框一获得焦点，键盘左边出现二维码；手机扫码打开网页，在手机上打字，电视输入框**实时同步**，点「发送」确认。不需要 ADB，不需要装手机 App，手机只需和电视同一个 Wi-Fi。
- 网页里还有方向键/确定/返回，可以在手机上操作电视当前的应用。
- 二维码带随机口令，只有扫码的手机能用；设置页可重置口令。

## 安装与启用

1. 从 Releases 的 `latest` 下载 `tv-ime.apk`，装到电视（U 盘，或 tv-adb 的推送安装）。
2. 打开「电视输入法」app（设置页），选一种方式启用并设为默认：
   - **一键**：先授权一次，再点「一键设为默认输入法」：
     ```
     pm grant com.lu.tvime android.permission.WRITE_SECURE_SETTINGS
     ```
     （电脑 `adb shell` 里执行，或用 tv-adb 的「执行命令」。）
   - **系统设置**：点「① 打开系统输入法设置」启用，再点「② 切换输入法」。
   - **命令**：`ime enable com.lu.tvime/.ImeService` 然后 `ime set com.lu.tvime/.ImeService`。
3. 想换回原来的输入法：设置页点「还原为原来的输入法」，或用 ② 切换。

## 说明

- 手机和电视要在同一局域网；网页地址是 `http://电视IP:8765/?k=口令`（端口被占用会顺延）。
- 手机输入时文字先作为“组合中的文字”同步到输入框，点「发送」才定稿；所以手机上边改边同步，电视里不会留下半截文字。
- 本输入法没有拼音候选；电视上要打中文请用手机扫码。
